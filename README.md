# Alexander’s Game — The Making
Curated static development journal. Open index.html; no install or build needed.

Original concept art is embedded once in the self-contained HTML. No external image host is required. No network dependencies, tracking, login or collection endpoints. Browser-local theme and reading-position storage only. The game prototype is not bundled or made public.

GitHub Pages: publish this directory as the root of a separate public journal repository. Keep the existing research/development repository private. Do not export the private repository history, source, prompts, source decks or third-party imagery.

The public journal is a reviewed snapshot. Update its edition, evidence and content deliberately; never automatically mirror arbitrary research files.
